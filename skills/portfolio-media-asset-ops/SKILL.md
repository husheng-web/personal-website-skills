# Portfolio Media Asset Ops

Safely turn approved media into website-ready assets.

## Workflow

1. Inspect the existing media directory conventions and every code/data reference before renaming, replacing, or converting an asset.
2. Record source provenance, approval state, media role, original dimensions, target format, and intended responsive use.
3. Use the smallest suitable optimized derivative while retaining the approved source asset unless the user explicitly authorizes removal.
4. Update all required registry/content references, dimensions, and localized alt text together.

## Checks

Verify paths resolve in the production build, images load without distortion, visual quality is adequate at the largest rendered size, and decorative images are correctly marked rather than given misleading alt text. Test desktop and mobile crop behavior for cover assets.

## Boundary

Never replace factual project material with generated imagery, imply rights from local possession, or delete originals as part of routine optimization.
